# 📚 Fundamentos de TI

Repositório com documentação de estudos sobre conceitos fundamentais de Tecnologia da Informação, essencial para profissionais de QA e desenvolvimento.

---

## 📋 Documentações disponíveis

### 1. [Software e Hardware](software-hardware.md)
Explicação sobre a diferença entre componentes físicos de um computador e os programas que executam nele.
- **Hardware:** Peças físicas (placas, monitor, teclado, disco rígido)
- **Software:** Programas e aplicativos que fazem o computador funcionar
- **Sistema Operacional:** Gerencia hardware e aplicações

---

### 2. [Redes de Computadores](redes-de-computadores.md)
Conceitos fundamentais sobre redes, conectividade e comunicação entre dispositivos.
- **Tipos de Redes:** PAN, LAN, MAN e WAN
- **Componentes:** Dispositivos, meios de transmissão e protocolos
- **Topologias:** Estrela, Barramento, Anel e Malha
- **Internet, Web, HTTP e HTTPS:** Protocolo de comunicação e segurança

---

### 3. [Ambientes de Software](ambientes-de-software.md)
Descrição dos três principais ambientes onde um sistema passa antes de chegar ao usuário final.
- **Desenvolvimento (Dev):** Onde o código é criado e testado inicialmente
- **Homologação (Staging):** Ambiente que simula a produção para validação final
- **Produção (Prod):** Sistema disponível para usuários reais
- **Fluxo de Deploy:** Como o código transita entre os ambientes

---

### 4. [Cliente-Servidor](cliente-servidor.md)
Explicação da arquitetura cliente-servidor e como funcionam os servidores.
- **Definição:** Servidor como recurso central que atende solicitações de clientes
- **Tipos de Servidores:** Web, E-mail, Arquivo/Backup
- **Funcionamento:** Operação 24/7 com hardware de alta performance
- **Virtualização:** Um servidor físico dividido em múltiplos virtuais

---

### 5. [Frontend, Backend e Banco de Dados](frontend-backend-banco-de-dados.md)
As três camadas principais do desenvolvimento de sistemas web e como se comunicam.
- **Frontend:** Interface visual (HTML, CSS, JavaScript)
- **Backend:** Lógica do sistema e regras de negócio
- **Banco de Dados:** Armazenamento estruturado de informações
- **Fluxo de Comunicação:** Como as três camadas interagem
